Aircraft Fuel Calculator v1.2 — personal reference prototype.

For iPhone Home Screen installation, publish all files in this folder together at an HTTPS website (e.g. GitHub Pages). In Safari open the published URL, Share > Add to Home Screen > Add. Visit once online to cache files, then test in Airplane Mode.

GitHub Pages makes the code publicly accessible. Entered values are not transmitted by the app or stored permanently. Do not enter confidential company information unless authorized.

Use is not approved for operational maintenance, refuelling, or dispatch decisions. Verify procedures and discrepancies independently.
